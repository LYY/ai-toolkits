## Evaluation Boundaries

Raw producer responses, independent grader outputs, and graded RED/GREEN receipts live only under ignored `.omo/evidence/omo-formal-plan-dual-review-eval/`. The validator is an offline contract checker: it does not invoke models, schedule reviewers, or define runtime protocol state. Each raw response carries a compact JSON envelope with case ID, structured outcome, observations, and unconstrained narrative. Structured outcomes and observation IDs make behavior case-specific without constraining prose. A valid RED capture may contain both passing and failing criteria; every criterion has grader evidence and each false receipt criterion also names a causal observation.
